## 关键排查结论（重要）
- `build.ps1` 直接调用 javac 报 "Compilation FAILED" 但无任何输出、`$LASTEXITCODE` 为空 —— 这是 PowerShell 调用 javac.exe 的异常，并非源码错误。
  - bash 里直接跑 javac 编译成功（仅 AICompletionMenuBuilder.java 弃用 API 警告）。
  - 因此本次用 bash 手动完成了编译+打包流程。
- MANIFEST.MF 位置错位：build.ps1/rebuild.ps1 期待根目录 `META-INF/MANIFEST.MF`，此前只在 `bin/META-INF/`。已在根目录补齐，后续脚本可直接复用。
- 编译命令要点：javac 是 Windows 程序，不接受 Git Bash 的 `@/tmp/...` 和带引号行参；需用 Windows 路径 argfile（`@D:\...\file.txt`，每行 `"路径"`）传源码列表。
